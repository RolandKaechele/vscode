= VS Code Changelog
:toc:
:toclevels: 1

Release-by-release changelogs for this fork, tracking bug fixes and
enhancements merged in from the upstream https://github.com/microsoft/vscode[microsoft/vscode]
release branches. Each release provides two variants:

* *fork* — only the changes actually applied to this fork (excludes
  `extensions/copilot`, which this fork does not ship).
* *full upstream* — the complete upstream change set, including the
  `extensions/copilot`-scoped changes that were intentionally left out.
