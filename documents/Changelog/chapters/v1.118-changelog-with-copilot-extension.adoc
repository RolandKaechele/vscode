:toc:
:toclevels: 1
:sectnums:

Bug fixes and enhancements merged from upstream `release/1.118` into
`release/1.117`, covering the complete upstream change set, split into the
core/workbench changes (also applied to this fork) and the changes scoped to
the `extensions/copilot` built-in extension (NOT applied to this fork - see
link:v1.118-changelog-without-copilot-extension.adoc[the fork changelog] for
what actually landed here). Each entry links to the originating pull request
on https://github.com/microsoft/vscode[microsoft/vscode] where one could be
identified from the commit message.
